# B-Systems brand assets — drop zone

`tokens.css` in this folder is the canonical token file for App B (B-Systems CRM)
and App C (Partnership Portal). The condensed rulebook lives in
`.claude/skills/bsystems-brand/SKILL.md`; the full spec is SPEC.md §4.3; the official
brand book PDF ("Edition 01 · April 2026") is the ultimate reference.

## Founder: drop these files here (any format is fine — the agent adapts)

- `logo-horizontal.(svg|png)` — primary lockup: gradient S-mark + SYSTEMS wordmark + tagline (light backgrounds)
- `logo-stacked.(svg|png)` — stacked mono-indigo version for square/vertical spaces
- `logo-mark.(svg|png)` — gradient S-mark alone (favicon / app icon / avatar)
- `logo-mono.(svg|png)` — single-color lockup, always Indigo #1D267D

## Fonts

Raleway, Inter, and JetBrains Mono are on Google Fonts — the agent self-hosts or
loads them; nothing to drop here.

## Agent instructions

Reference the filenames actually present, respect minimum sizes (120px lockup /
24px icon) and 1×-icon-height clear space, never place the gradient logo on a
gradient surface, and record the asset mapping as an ADR.
